KWALIFY - FIRST TIME SETUP (Windows)
====================================

Spotify login needs https://kwalify.net (Spotify does not allow localhost), which
reaches this PC through a Cloudflare Tunnel - no router port forwarding.


ONE-TIME PREREQUISITES
----------------------
1. Node.js 20 LTS          https://nodejs.org   (repo has .nvmrc = 20)
2. PostgreSQL 18           https://www.postgresql.org/download/windows/
   Database setup helper (Admin PowerShell, once): scripts\setup-local-dev.ps1
3. Spotify Developer app   https://developer.spotify.com/dashboard
   Settings -> Redirect URIs -> add exactly:
     https://kwalify.net/api/auth/callback
   Put Client ID and Client Secret into .env (copy .env.example to .env first)


ONE-TIME SELF-HOST SETUP
------------------------
  setup-self-host.bat
    - sets .env for kwalify.net (APP_URL, redirect URI, NODE_ENV=production, ...)
    - installs cloudflared if missing, runs the Cloudflare login, creates
      deploy\cloudflared.yml for the tunnel
    - does NOT register scheduled tasks or login auto-start

  If you used the OLD launchers (start.bat / start-kwalify.bat) on this PC:
    TURN-OFF-AUTOSTART.bat   (once) removes their scheduled tasks, watchdog and
                             dead Desktop shortcuts.


DAILY USE
---------
  Start:  KWALIFY-START.bat          (server + Cloudflare tunnel when self-hosting)
  Stop:   KWALIFY-STOP.bat
  Local only, no tunnel:  KWALIFY-START.bat local

  Public site: https://kwalify.net (while the tunnel window is open)
  This PC:     http://127.0.0.1:5000

  See START-HERE.txt for exactly what START / STOP do.


TROUBLESHOOTING
---------------
  * Read the "Kwalify server" window - every check prints [ok] or [!!] with
    what to do. If the build fails, Kwalify is not started.
  * Port 5000 already in use by another program: START tells you which one and
    leaves it alone. Close it or change PORT in .env.
  * kwalify.net does not load on THIS PC but works elsewhere: the hosts file
    probably still has "127.0.0.1 kwalify.net" from the old local-domain mode.
    Right-click remove-local-hosts.bat > Run as administrator.
  * Tunnel problems: keep the minimised "cloudflared" window open; DNS repair:
    fix-cloudflare-dns.bat; re-run setup-self-host.bat if deploy\cloudflared.yml
    is missing.
  * Spotify login fails: the redirect URI must be
    https://kwalify.net/api/auth/callback
  * Health:  http://127.0.0.1:5000/api/readyz   https://kwalify.net/status
  * API log: kwalify-api.log


BENCHMARKS
----------
  With Kwalify running: http://127.0.0.1:5000/benchmark  (control panel)
  CLI: start-kwalify-benchmark.bat  (menu; "smoke" ~2 min, "large" ~4 h)
