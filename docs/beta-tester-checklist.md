# Kwalify beta tester checklist

Use this after your **first generation** and again after your **fifth** (once the product has had time to surprise you).

## After first generation

Rate each 1–5 (1 = not at all, 5 = completely).

| Question | Score (1–5) | Notes |
|----------|-------------|-------|
| Did it feel like it understood your prompt? | | |
| Did you rediscover a song you had forgotten? | | |
| Did the playlist feel like a journey, not just a mood list? | | |
| Would you share it with someone? | | |
| Would you make another one? | | |

### Quick yes/no

- [ ] The result page felt personal — not like an “AI tool”
- [ ] The journey sections (Leaving / The open road / Arrival) made sense for your moment
- [ ] Nothing on the page felt overly technical (confidence %, “neutral”, BPM, etc.)
- [ ] You knew what to do next (Play on Spotify, share, or try another prompt)

## After five generations

| Question | Score (1–5) | Notes |
|----------|-------------|-------|
| Does Kwalify feel like *your* music, not generic Spotify? | | |
| Is the gallery starting to feel like a diary of your life? | | |
| Are you learning to write better prompts? | | |
| Would you recommend it to a friend who loves music? | | |

## If something felt wrong

Note:

1. **Exact prompt** you used
2. **What you expected** vs what you got
3. **One track** that felt perfect and **one** that felt wrong
4. Screenshot of the result page (especially journey + “Why this fits”)

Send via the Feedback link in the site footer (include your Spotify email if login issues).

## What we are *not* measuring yet

- Raw match accuracy / BPM / valence scores
- How fast generation completes
- Whether every journey act title is perfect

Reactions and emotional fit matter more than metrics at this stage.
