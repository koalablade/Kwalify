Kwalify could not start

The launcher hit a problem. Try these steps in order.

What happened

The start script exited with an error. Check kwalify-start.log in the project folder.

Quick fixes

  1. Double-click stop-kwalify.bat, then start.bat again.
  2. Right-click start.bat → Run as administrator if HTTPS or tunnel setup fails.
  3. Confirm Spotify redirect URI: https://kwalify.net/api/auth/callback
  4. Run once as Admin: scripts\setup-local-dev.ps1 (database)
  5. Run: npm run setup:local-domain (HTTPS certs)

Health checks (after a successful start)

  • https://kwalify.net/api/readyz
  • http://127.0.0.1:5000/api/readyz

Desktop shortcuts

Run create-kwalify-shortcuts.bat once — adds Start Kwalify and Stop Kwalify to your Desktop.
