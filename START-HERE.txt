KWALIFY - START / STOP
======================

  KWALIFY-START.bat   Double-click to run Kwalify.
                      A "Kwalify server" window opens and shows what is happening:
                      checks, build (only if the code changed), then server logs.
                      When it says "Kwalify is running" open the address it shows
                      (http://localhost:5000 on this PC; https://kwalify.net when
                      self-hosting). Keep that window open while you use Kwalify.

  KWALIFY-STOP.bat    Double-click to stop Kwalify cleanly. Ctrl+C in the
                      "Kwalify server" window does the same.

  Kwalify is completely OFF until you double-click KWALIFY-START.bat.
  Nothing starts on its own, at boot or at login, and nothing restarts it.

  KWALIFY-START.bat local   Run on this PC only (no Cloudflare tunnel).


WHAT START / STOP DO AND DO NOT DO
----------------------------------
  * PostgreSQL must already be running. START checks it and tells you how to
    start it if not. START/STOP never start, stop or change the database.
  * START never starts a second copy. If Kwalify is already running it says so.
  * START does not pull from git, edit .env, or need Administrator.
  * Cloudflare tunnel (kwalify.net): started only when this PC is set up for
    self-hosting (setup-self-host.bat done: .env KWALIFY_HOST_MODE=selfhost and
    deploy\cloudflared.yml present). It runs in its own minimised window.
  * STOP only stops the Kwalify server started from this folder, and the tunnel
    only if START started it. It never kills "whatever is on port 5000" and
    never stops PostgreSQL or other programs. If Kwalify is not running it
    just says so.


FIRST TIME ONLY
---------------
  setup-self-host.bat          .env for kwalify.net + Cloudflare tunnel (once)
  TURN-OFF-AUTOSTART.bat       Removes leftovers of the OLD launchers: Kwalify
                               scheduled tasks (start at login, 5-minute uptime
                               check, weekly maintenance, nightly backup),
                               Startup-folder entries, the health-watch watchdog,
                               and Desktop shortcuts to launchers that no longer
                               exist. Run once; if it says access denied,
                               right-click > Run as administrator.
  create-kwalify-shortcuts.bat Optional Desktop shortcuts (Start / Stop / Maintain)


REGULAR UPKEEP (manual, nothing is scheduled)
---------------------------------------------
  maintain.bat          Once a week: readiness, backups, routes
  production-ready.bat  Occasionally: am I production ready?
  npm run backup:db     Database backup whenever you want one
